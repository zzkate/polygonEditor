Как пользоваться
Скомпилируйте проект (Qt5, C++11).

Запустите.

нажмие на кнопку «Загрузить изображение» и выберите файл. ( загрузка изображения приводит к сбрасыванию всех созданных ранее полигонов)

Левая кнопка мыши:

клик по пустому месту изображения — новая вершина текущего полигона; (незавершенный, формируемый полигон)

клик по вершине — перетаскивание вершины
(редактирование вершин происходит на оригинальном - не перемещенном полигоне, на изображении он закрашивается белым, "дырка");

клик внутри полигона — выбор полигона, затем перетаскивание — перемещение полигона.
(выбранный полигон помечен красной рамкой, невыбранный синей)

Завершить полигон:

правая кнопка мыши или Enter. ( после завершения полигон помечается красной рамкой как выбранный и готовый к перемещению)

Удалить выбранный полигон: клавиша Delete. (для удаления полигон должен быть выбран, помечен красной рамкой)

возможные улучшения и ограничения:
- можно реализовать через QGraphicsPolygonItem, QGraphicsScene
- добавление точек в полигон не по порядку а между ближайшими вершинами
- удаление вершин
- откат последней операции по ctrl-z
- поддержка ресайза изображения(пропорциональный ресайз всех полигонов и "дырок" в изображении)
- если переместили фрагмент за пределы экрана - его больше нельзя выделить(удалить, переместить) - предовратить перемещение за пределы экрана
- логирование и обработка ошибок - сейчас они игнорируются
- проверка корректности и безопасности файла с изображением(считаем что в файле с расширением изображения находится валидное изображение)
- не используется файл переводов
- допускаеся создание полигонов в области "дырок"
