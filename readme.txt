Как пользоваться
Скомпилируйте проект (Qt5, C++11).

Запустите.

Правой кнопкой → «Загрузить изображение» и выберите файл.

Левая кнопка мыши:

клик по пустому месту — новая вершина текущего полигона;

клик по вершине — перетаскивание вершины;

клик внутри полигона — выбор полигона, затем перетаскивание — перемещение полигона.

Завершить полигон:

правая кнопка мыши или Enter.

Удалить выбранный полигон: клавиша Delete.

возможные улучшения: адаптировать под конкретную структуру проекта (например, отдельные классы для сцены, хранение полигонов в модели, работа с координатами изображения 1:1).
